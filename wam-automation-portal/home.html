WAM Automation Tool Modules

WAM Automation Portal Module

This module provides the user interface for managing test plans, executing tests, and tracking progress. Key features include:

  • User Role Management
  • Test Plan Creation
  • Test Execution & Reporting

WAM Automation Engine Module

The backend engine that processes test case execution, log verification, database validation, and more. It can also be deployed in a distributed setup for more complex environments.

Test Case Creation Workflow

  1. Test Plan: Create a Test Plan to organize multiple test cases.
  2. Test Cases: Define test cases under each plan to automate specific scenarios.
  3. Test Case Steps: Specify step-by-step actions for each test case.
  4. Test Case Step Parameters: Fine-tune each step by setting parameters to customize the execution.
